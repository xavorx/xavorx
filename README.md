## 🔒 About

**XAVOR Anti-Cheat** is a security solution built to protect FiveM communities from cheaters, modders and exploiters. We detect threats in real time, block them before they cause damage, and give server owners full visibility and control.

> Fair play, stable economy, happy players.

## ⚡ What We Protect Against

| Threat | Protection |
|---|---|
| 🎯 **Aimbot / Triggerbot** | Behavioral analysis and server-side hit validation |
| 👻 **Noclip / Godmode / Speedhack** | Continuous movement and state verification |
| 💣 **Explosions & Entity Spam** | Spawn limits, ownership checks and automatic cleanup |
| 💉 **Mod Menus & Injection** | Resource integrity and blacklisted menu detection |
| 💰 **Money / Item Exploits** | Server-authoritative economy and trigger-token protection |
| 🧩 **Malicious Events** | Event validation, rate limiting and payload checks |
| 🚫 **Ban Evasion** | Multi-identifier and hardware-aware ban system |

## ✨ Features

- 🔴 **Real-time detection** with automatic punishment (warn, kick, ban)
- 🧠 **Low false positives** through multi-layer verification
- 📸 **Screenshot evidence** attached to every detection
- 📋 **Discord webhook logs** for instant staff alerts
- 🖥️ **Admin panel** for bans, reports and player history
- 🔧 **Fully configurable** detections and punishments
- ⚙️ **Optimized** for minimal resource usage
